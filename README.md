What's for Dinner!

Description:
What's for Dinner is a java web application which was designed to allow users to manage and utilize recipes. The app will be a cooking aid, allowing users to build a personal recipe library, save recipes as favorites, and search for recipes using varying levels of criteria.

Features:
Store and manage recipes.
Save recipes as favorites.
Search recipes by tag, protein, or ingredients list.

Technologies used:
Java.
Web Apllication Technologies (HTML).

How to Run:
The library is pre-loaded with three recipes which can be viewed by selecting the recipe library. Here you can see recipes with spoiler ingredients lists, you have the option to add to favorites(if not a favorite), and to update or delete recipes. Select home to return to the menu screen or select add recipe to add a recipe to the library. Select search to input parameters for the search. Searching by tag (Style), like Italian, or Mexican, by protein, like chicken or beef, or finally by an ingredients list which will return the best matched recipe for your ingredients in descending order.
